Admin setup

One-time setup on this device. Connect your GitHub account with a token, then choose an admin password.

How do I get a GitHub token?
  1. Open GitHub → Fine-grained token (logged in as Arkan17).
  2. Token name: Arkoid Admin. Expiration: 1 year (or your choice).
  3. Repository access: “Only select repositories” → arkan17.github.io.
  4. Permissions → Repository permissions → Contents: “Read and write”.
  5. Click Generate token, copy it, and paste it below.

The token is encrypted with your admin password and saved only in this browser. It is never sent anywhere except GitHub.
