About Arkan Apps

Arkan Apps is the home of Android applications developed by Arkan17. Instead of going through an app store, you can download each app directly as an APK file.

How downloads work

All APK files are published through GitHub Releases. When you press “Install APK”, the file comes straight from GitHub’s servers — this website never stores or modifies the files.

Installing an APK

  • Download the APK from the app’s page.
  • Open it from your notifications or the Downloads folder.
  • If Android asks, allow “Install unknown apps” for your browser or file manager.
  • Tap Install. Updates install over the existing version and keep your data.

Staying safe

Only download Arkan Apps from arkan17.github.io or the official GitHub repositories. Copies hosted elsewhere may have been tampered with.
